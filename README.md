# Project Cube

Project Cube is a personal 3x3 speedcubing coaching system. The six-month objective is to progress from a 50+ second average toward a consistent sub-30-second average.

## Scope

This project focuses on:

- recording training context and results;
- producing detailed daily sessions with focus areas, drills, workloads, and scrambles;
- identifying weaknesses across Cross, F2L, OLL, PLL, recognition, execution, and transitions;
- turning evidence into focused weekly practice plans;
- evaluating CFOP, Roux, ZZ, or other methods when a method change could remove a real bottleneck;
- tracking progress toward a stable sub-30 average.

This project does **not** implement a timer. All solve timing and raw solve history come from [csTimer](https://www.cstimer.net/).

## Online Dashboard

The online dashboard is available at [linyinzhou.github.io/project-cube](https://linyinzhou.github.io/project-cube/). It provides switchable views for today's session, the current seven-session training cycle, and the six-month roadmap.

## Vault Structure

- `Dashboard.md`: current focus, quick links, and next actions.
- `Assessments/`: baseline and periodic assessments.
- `Plans/`: six-month, weekly, and daily training plans.
- `Training Logs/`: completed training-session notes.
- `Weekly Reviews/`: weekly results and next-week decisions.
- `Templates/`: reusable Obsidian note templates.
- `Data/`: exported csTimer data and derived datasets.

## Training Loop

1. Time solves in csTimer using a dedicated session.
2. Complete a training log with the session metrics and observations.
3. Review trends weekly instead of reacting to individual solves.
4. Select one primary bottleneck and one supporting skill for the next week.
5. Reassess phase splits and the rolling average every four weeks.

## Getting Started

1. Open this folder as an Obsidian vault.
2. Open `Dashboard.md`.
3. Start with `Plans/Week 01 - CFOP Foundation.md`.
4. Complete `Assessments/Baseline Assessment.md` using fresh csTimer solves.
5. Use `Templates/Training Session.md` for each focused practice session.
6. Use `Templates/Weekly Review.md` at the end of each week.

## Success Criteria

The final target is not a lucky sub-30 single. Success means a repeatable sub-30 average supported by improving consistency and controlled phase times, regardless of the method ultimately selected.
